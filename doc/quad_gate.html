QuAdGate 角点检测模块分析

基于分割掩码的四边形门角点检测，支持部分可见性和遮挡处理

一、模块概述

quad_gate.py 实现了无人机竞速中门的角点检测功能。该模块接收来自 GateNet 的分割掩码，提取门的四个角点坐标，为后续的 PoseEstimator 提供输入数据。

模块工作流程

分割掩码 → 轮廓检测 → 多边形逼近 → 角点排序 → 置信度计算

二、GateDetection 数据类

功能：存储门角点检测的结果数据

字段名 类型 说明
corners np.ndarray (4x2) 按 TL、TR、BR、BL 顺序排列的角点坐标
confidence float [0, 1] 检测置信度
is_complete bool 是否检测到完整的4个角点
visible_corners int (0-4) 可见角点数量
contour Optional[np.ndarray] 原始轮廓数据
center Optional[np.ndarray] 门在图像中的中心坐标

三、QuAdGate 角点检测器

功能：从分割掩码中检测门的四个角点，支持部分可见性处理

3.1 初始化参数

参数名 类型 默认值 说明
min_contour_area int 100 最小轮廓面积（像素），过滤噪点
epsilon_factor float 0.02 轮廓逼近因子（相对周长）
max_corner_distance float 10.0 帧间角点匹配的最大距离
confidence_threshold float 0.5 最小检测置信度阈值

3.2 detect() 方法 - 核心检测

功能：从分割掩码中检测门角点

def detect(self, mask: np.ndarray, return_all: bool = False) -> Optional[GateDetection]

执行步骤：

  1. 掩码预处理：转换为 uint8 格式，阈值二值化
  2. 轮廓检测：使用 cv2.findContours() 提取外部轮廓
  3. 轮廓过滤：面积小于 min_contour_area 的轮廓被丢弃
  4. 轮廓处理：对每个轮廓调用 _process_contour()
  5. 结果选择：返回置信度最高的检测结果或全部结果
返回值： GateDetection 对象或 None（未检测到门）

3.3 _process_contour() 方法 - 轮廓处理

功能：处理单个轮廓，根据顶点数量采用不同策略提取角点

def _process_contour(self, contour: np.ndarray, image_shape: Tuple[int, int]) -> Optional[GateDetection]

处理策略分支：

4 个顶点（理想情况）
  • 直接使用逼近后的角点
  • 调用 _order_corners() 排序
  • 置信度：完整计算
3 个顶点（三角形）
  • 使用平行四边形法则估算第4个角点
  • 调用 _complete_from_triangle()
  • 置信度：乘以 0.7 系数
>4 个顶点（复杂轮廓）
  • 使用最小面积矩形拟合
  • 调用 cv2.minAreaRect()
  • 置信度：乘以 0.8 系数
<3 个顶点（不完整）
  • 同样使用最小面积矩形拟合
  • 置信度：乘以 0.5 系数

3.4 _order_corners() 方法 - 角点排序

功能：将角点按固定顺序排列：Top-Left → Top-Right → Bottom-Right → Bottom-Left

def _order_corners(self, corners: np.ndarray) -> np.ndarray

排序算法：

  1. 利用坐标和：TL 的和最小，BR 的和最大
  2. 利用坐标差：TR 的差最小（x-y 最小），BL 的差最大
  3. 冲突处理：如果索引重复，使用质心+角度排序作为备选方案

3.5 _complete_from_triangle() 方法 - 三角形补全

功能：从3个可见角点估算第4个缺失角点

def _complete_from_triangle(self, corners: np.ndarray, center: np.ndarray) -> np.ndarray

算法原理：

基于平行四边形法则：在平行四边形中，对角顶点之和相等

P4 = P1 + P3 - P2

执行步骤：

  1. 遍历3个角点的所有组合（3种组合）
  2. 对每种组合使用平行四边形法则计算候选第4点
  3. 调用 _rectangularity_score() 评估矩形度
  4. 选择矩形度最佳的候选点
  5. 如果失败，使用中心镜像作为备选方案

3.6 _rectangularity_score() 方法 - 矩形度评估

功能：评估四边形的矩形程度，分数越低越接近矩形

def _rectangularity_score(self, corners: np.ndarray) -> float

评分指标：

  • 边长差异：对边长度应相等，计算差值和
  • 角度偏差：相邻边应垂直（90°），计算余弦值绝对值和

score = length_diff + angle_dev

3.7 _compute_confidence() 方法 - 置信度计算

功能：综合评估检测结果的置信度

def _compute_confidence(self, corners: np.ndarray, area: float, perimeter: float) -> float

置信度组成（加权求和）：

矩形度 (40%)
rect_confidence = max(0, 1 - score/10)
面积合理性 (30%)
预期范围: 50-3000 像素
宽高比 (30%)
合理范围: 0.5-2.0

3.8 track_corners() 方法 - 帧间跟踪

功能：在相邻帧之间跟踪角点，保持时间一致性

def track_corners(self, prev_detection: GateDetection, curr_detection: GateDetection) -> GateDetection

执行步骤：

  1. 计算前后帧角点之间的距离矩阵
  2. 使用贪心算法进行角点匹配（简化版匈牙利算法）
  3. 匹配距离超过 max_corner_distance 的角点保持前一帧位置
  4. 对匹配成功的角点应用指数平滑（当前帧权重 0.7）

四、GateTracker 跟踪器

功能：多帧门跟踪器，提供时间滤波和轨迹维护

4.1 初始化参数

参数名 类型 默认值 说明
detector QuAdGate - 角点检测器实例
smoothing_alpha float 0.7 指数平滑因子
max_missed_frames int 5 最大连续丢失帧数

4.2 update() 方法

def update(self, mask: np.ndarray) -> Optional[GateDetection]
接收掩码 → 调用 detect() → 时间平滑 → 更新状态
丢帧处理：连续丢失帧数超过 max_missed_frames 时，重置跟踪状态

五、visualize_detection() 可视化函数

功能：在图像上绘制检测结果，便于调试和展示

def visualize_detection(image: np.ndarray, detection: Optional[GateDetection], mask: Optional[np.ndarray] = None) -> np.ndarray

绘制内容：

  • 分割掩码叠加：绿色半透明显示
  • 角点标记：四种颜色分别标记 TL/TR/BR/BL
  • 四边形轮廓：青色边框
  • 中心点：品红色圆点
  • 置信度文本：左上角显示

七、关键技术要点

部分可见性处理

通过平行四边形法则从三角形估算第4个角点，提高遮挡场景下的鲁棒性

时间一致性

帧间角点跟踪和指数平滑，减少检测抖动

多级置信度评估

综合矩形度、面积、宽高比三个维度评估检测质量

最小面积矩形拟合

复杂轮廓情况下的备选方案，确保始终能输出4个角点
