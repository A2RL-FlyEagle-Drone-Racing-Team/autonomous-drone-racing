# 自主无人机竞速项目 (Autonomous Drone Racing)

一个基于深度学习和强化学习的自主无人机竞速系统，支持端到端视觉导航和实时控制。

## 项目架构

```
autonomous-drone-racing/
  ├── src/ # 核心源代码
  │   ├── control/ # 控制模块
  │   │   ├── gcnet.py # G&CNet神经网络控制器
  │   │   ├── motor_mixer.py # 电机混合器与PID控制
  │   │   └── race_pid_control.py
  │   ├── vision/ # 视觉模块
  │   │   ├── gate_net.py # 轻量级U-Net门检测网络
  │   │   ├── pose_estimator.py # PnP姿态估计器
  │   │   ├── quad_gate.py # 角点检测
  │   │   ├── data_collector.py
  │   │   └── data_loader.py
  │   ├── state/ # 状态估计模块
  │   │   └── ekf.py # 扩展卡尔曼滤波器
  │   ├── envs/ # 环境模块
  │   │   └── high_freq_racing.py # 高频竞速环境
  │   │   └── pipeline/ # 端到端管线
  │   └── vision_racing.py
  ├── scripts/ # 训练和测试脚本
  ├── models/ # 预训练模型
  ├── configs/ # 配置文件
  └── web/ # 可视化工具
```

## 核心模块功能

### 1. 控制模块 (`src/control/`)

#### G&CNet (Guidance and Control Network)
- **功能**: 神经网络控制器，直接输出电机RPM指令
- **输入特征** (22维):
  - 位置 (3): 无人机世界坐标
  - 速度 (3): 世界坐标系下的速度
  - 姿态 (4): 四元数表示
  - 角速度 (3): 机体坐标系下的角速率
  - 门位置 (3): 下一个门的世界坐标
  - 门方向 (3): 门的法向量
  - 速度目标 (3): 期望速度向量
- **输出**: 4个电机的归一化RPM值
- **架构**: 输入投影层 + 2个残差块 + 输出投影层

#### MotorMixer
- **功能**: 将期望推力和力矩转换为单个电机的RPM指令
- **支持配置**: X型和+型四旋翼配置
- **内置参数**: Crazyflie 2.X无人机的物理参数

#### 级联PID控制器
- **PositionController**: 位置PID控制，输出推力和目标姿态
- **AttitudeController**: 姿态PD控制，输出力矩指令
- **FullController**: 完整的级联控制器

### 2. 视觉模块 (`src/vision/`)

#### GateNet
- **功能**: 轻量级U-Net用于门的分割检测
- **特点**: 
  - 参数少于50万，适合嵌入式实时推理
  - 输入: 64x48 RGB图像
  - 输出: 二值分割掩码
- **损失函数**: 结合BCE和Dice Loss处理类别不平衡

#### PoseEstimator
- **功能**: 使用PnP算法从2D角点估计门的6-DoF姿态
- **输入**: 检测到的门角点坐标
- **输出**: 门在相机坐标系下的位置和姿态
- **特性**: 支持RANSAC鲁棒估计

#### QuAdGate
- **功能**: 从分割掩码中提取门的四个角点

### 3. 状态估计模块 (`src/state/`)

#### ExtendedKalmanFilter
- **功能**: 融合IMU预测和视觉测量的扩展卡尔曼滤波器
- **状态向量** (19维):
  - 位置 (3)
  - 速度 (3)
  - 姿态四元数 (4)
  - 角速度 (3)
  - 加速度计偏差 (3)
  - 陀螺仪偏差 (3)
- **特点**: 
  - 高频率预测 (500 Hz)
  - 低频率视觉更新 (24 Hz)
  - 支持PBRS奖励塑造

### 4. 环境模块 (`src/envs/`)

#### HighFreqRacingAviary
- **功能**: 高频竞速环境，基于gym-pybullet-drones
- **特性**:
  - 500 Hz控制频率
  - 直接电机RPM动作空间
  - 支持自定义赛道配置
  - 门穿越奖励机制
- **奖励函数**:
  - 门穿越奖励: +100
  - PBRS进度奖励
  - 方向速度奖励
  - 倾斜惩罚

### 5. 端到端管线 (`src/pipeline/`)

#### VisionRacingPipeline
- **功能**: 协调所有组件的端到端视觉竞速管线
- **工作流程**:
  ```
  相机(24Hz) → GateNet → QuAdGate → PoseEstimator
                                              ↓
                                    EKF(500Hz) ← IMU(500Hz)
                                              ↓
                                         G&CNet → 电机
  ```

## 安装指南

### 环境要求
- Python ≥ 3.8
- PyTorch ≥ 2.0
- gymnasium
- gym-pybullet-drones
- OpenCV
- NumPy

### 安装步骤

```bash
# 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt

# 安装项目
pip install -e .
```

## 快速开始

### 1. 测试环境

```python
from src.envs.high_freq_racing import HighFreqRacingAviary, create_monorace_track

# 创建赛道
track = create_monorace_track(num_gates=5)

# 创建环境
env = HighFreqRacingAviary(
    track=track,
    ctrl_freq=500,
    gui=True  # 启用可视化
)

# 运行测试
obs, info = env.reset()
for _ in range(1000):
    action = env.action_space.sample()  # 随机动作
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()

env.close()
```

### 2. 使用G&CNet控制

```python
from src.control.gcnet import GCNet

# 创建控制器
model = GCNet()

# 获取动作
rpms = model.get_action(
    position=np.array([0, 0, 1]),
    velocity=np.array([1, 0, 0]),
    orientation=np.array([1, 0, 0, 0]),  # 四元数 (w, x, y, z)
    angular_velocity=np.array([0, 0, 0]),
    gate_position=np.array([5, 0, 1]),
    gate_direction=np.array([1, 0, 0]),
    velocity_target=np.array([3, 0, 0]),
)
```

### 3. 使用完整视觉管线

```python
from src.pipeline.vision_racing import VisionRacingPipeline, PipelineConfig

# 配置
config = PipelineConfig(
    control_freq=500,
    vision_freq=24,
    gate_net_path="models/gate_net.pt",
    gcnet_path="models/gcnet.pt",
)

# 已知门位置
known_gates = {
    0: (np.array([2, 0, 1]), np.array([1, 0, 0, 0])),
    1: (np.array([4, 2, 1.2]), np.array([0.92, 0, 0, 0.38])),
}

# 创建管线
pipeline = VisionRacingPipeline(config=config, known_gates=known_gates)

# 重置并运行
pipeline.reset(
    initial_position=np.array([0, 0, 1]),
    initial_velocity=np.array([0, 0, 0]),
)

# 控制循环
for step in range(1000):
    current_time = step * 0.002
    
    # 获取相机图像
    rgb_image = get_camera_image()
    
    # 运行管线
    rpms, info = pipeline.step(
        current_time=current_time,
        rgb_image=rgb_image,
    )
    
    # 发送RPM指令到电机
    send_motor_command(rpms)
```

## 关键配置参数

### 控制参数
- `control_freq`: 控制频率 (默认: 500 Hz)
- `max_rpm`: 最大电机RPM (默认: 21702.64)
- `target_velocity`: 目标速度 (默认: 5.0 m/s)

### 视觉参数
- `vision_freq`: 视觉更新频率 (默认: 24 Hz)
- `image_size`: 图像尺寸 (默认: 64x48)
- `camera_fov`: 相机视场角 (默认: 60度)

### 奖励参数
- `reward_gate_passed`: 门穿越奖励 (默认: 100)
- `reward_velocity_bonus`: 速度奖励 (默认: 0.01)
- `reward_time_penalty`: 时间惩罚 (默认: -0.01)

## 项目特点

1. **高频控制**: 500 Hz控制频率，匹配真实无人机的控制需求
2. **端到端视觉**: 从图像输入到电机输出的完整管线
3. **多模态融合**: EKF融合IMU和视觉测量
4. **课程学习**: 支持渐进式难度训练
5. **模仿学习**: DAgger算法从专家演示中学习
6. **强化学习微调**: SAC算法进一步优化策略
